Fluids_MediaPlayer - custom font folder

To use your own font for the now-playing overlay without installing it in Windows:
1. Copy a .ttf, .otf or .woff2 file into this folder.
2. In the wallpaper's settings, type the file name into "Extra font", e.g.  MyFont.ttf

If the font IS installed in Windows, just type its name instead (e.g. Spotify Mix); no file needed.
