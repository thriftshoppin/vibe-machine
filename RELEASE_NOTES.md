# Vibe Machine v2.0.0

The first complete release of Vibe Machine as a standalone Lively Wallpaper package.

- Includes the full wallpaper runtime, settings, player overlay, fonts, previews, and background assets.
- Uses Lively's live audio feed to drive the fluid visualizer and its now-playing interface for the player card.
- Adds America, Fireplace, and Neon color modes.
- Includes multi-monitor and Lively Span behavior, per-monitor wave sizing, and performance controls.
- Keeps settings for palette behavior, simulation, backgrounds, and overlays.

## Install

Download `Vibe-Machine-v2.0.0.zip`, then import it using **Lively → Add Wallpaper → Choose file** or drag the ZIP into Lively.
